## Featured project

### [PDF Deep Reader](https://github.com/manrods/pdf-deep-reader-skill)

A local-first, token-efficient PDF extraction and retrieval system for AI agents. It preserves page, section, table, figure, confidence, and citation metadata so answers remain grounded in inspectable evidence.
